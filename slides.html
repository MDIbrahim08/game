2. THE TECHNICAL GAP

Why Current Solutions Break

Traditional techniques force an unacceptable trade-off between security, speed, and accuracy.

Approach 1: Fine-Tuning
❌ Expensive & Fragile

• Costs $100K+ per training run.
• Breaks when a new foundation model drops.
• Degrades general coding power ($Pass@1$) by up to 7.9%.

Approach 2: Post-Commit SAST
❌ Alert Fatigue

• Tools like SonarQube run after code is committed.
• Produce 60–80% false positive noise.
• Developers ignore alerts to meet shipping deadlines.

Approach 3: Naive RAG
❌ 81.5% Noise

• Dumps raw 90-line CVE files.
• Irrelevant boilerplate distracts the LLM.
• Pure text similarity misses API misuse semantics.

3. THE BREAKTHROUGH ARCHITECTURE

RESCUE: Two-Stage Hybrid Framework

Published at ICLR 2026 (Purdue University Research).

🏗️ Offline: Hybrid Knowledge Distillation

1. Cluster-Then-Summarize:
Recursively distills raw CVEs into actionable high-level CWE guidelines and root vulnerability causes.

2. Program Dependence Graph (PDG) Slicing:
Applies 2-hop bidirectional reachability slicing around deleted (vuln) and added (fix) statements.

⚡ Result: Cuts 81.5% token noise (89.5 -> 16.1 LoC) with 100% fix retention.

⚡ Online: Hierarchical Multi-Faceted Retrieval

Proactively analyzes 3 security facets:
• Facet 1 (Vcause): Dense search of root vulnerability cause.
• Facet 2 (API Pattern): AST visitor extraction & BM25.
• Facet 3 (Code Sim): Dense matching with sliced code.

Modified Reciprocal Rank Fusion (RRF):
Fuses facets with confidence thresholds (τ) and 2-step hierarchy.

🎯 Zero-training, sub-50ms inference, zero data leakage.
